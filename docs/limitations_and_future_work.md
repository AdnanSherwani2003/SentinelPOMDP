# Limits and evidence-based future work

- Olist does not record outcomes of unperformed investigations. Autonomous POMDP
  value versus simpler policies remains NOT EVALUABLE. A future prospective pilot
  would need authorized action logs and independently reviewed outcomes.
- Procurement fixtures verify software behavior only. Real use needs approved
  document mappings, explicit financial rules and representative held-out records.
- Olist predictive candidates are not activated. A historical forecast score is
  distinct from a factual delivery lookup and from a causal investigation benefit.
- Probability models retain their stated fixed-state/conditional-independence
  assumptions. Source grouping prevents obvious duplicate support but cannot prove
  statistical independence or the truth of a source.
- The legacy grid belief-weight constructor retains its documented uniform fallback
  for an all-zero weight vector. It rejects negative/non-finite weights. Registered
  investigation priors require normalized probabilities and reject invalid distributions.
- Domain packs are declarative governance/configuration. New semantics may require
  a reviewed adapter; uploaded code and unrestricted graph queries are unsupported.
- Authenticator, throttling and synchronous traces remain process-local. Only one
  API process is validated. Shared identity/throttling is future work if needed.
- Document metadata uses local atomic files and version scans. Multi-process
  document authoring and large registries need further coordination/load validation.
- Neo4j Community dump needs downtime. Backup checksums detect corruption; they do
  not establish source truth or encryption. Production recovery objectives are unmeasured.
- Cancellation waits for safe boundaries. Ambiguous external effects are marked
  NEEDS_RECONCILIATION. No claim is made of universal exactly-once external effects.
- No public deployment, distributed HA proof, independent penetration test,
  production certification, customer adoption or business-impact estimate is claimed.
- Remote CI is configured but was not triggered in I20. Tracked generated artifacts
  and inherited uncommitted files still require the owner's reviewed Git checkpoint.

The next practical work is the reviewed source-control checkpoint, followed by an
explicitly scoped real-data pilot or deployment hardening decision. No Implementation
21 was created automatically.
